# ServeSync Play Data safety working inventory

Updated 2026-09-29. This is a source-backed worksheet for the Play Console form, **not a submitted declaration**. The Console is saved through Step 2; Step 3 (data types) remains unanswered. Google requires the form to cover data sent by the app and its SDKs, including optional features. [Google's Data safety instructions](https://support.google.com/googleplay/android-developer/answer/10787469). The Console dashboard now shows 9 of 11 setup tasks complete.

## Evidence and release gate

- `public/privacy.html` describes account, church, communication, notification, provider, and activity data, with current retention limitations.
- `src/pages/Messages.tsx`, `src/components/AnnouncementComposerForm.tsx`, `src/pages/Profile.tsx`, and `src/pages/Onboarding.tsx` expose the media upload paths.
- `src/components/VoiceKeyDetector.tsx` processes microphone input locally; `supabase/migrations/20260923033724_android_native_push_devices.sql` shows the installation identifier and token storage.
- The Play manifest for the rebuilt code 33 declares Internet, notifications, camera, and microphone; it does not declare location or contacts permissions.
- `src/pages/leadership/OrganizationBilling.tsx` can submit payer name, payment channel, billing reference, and a receipt for non-exempt churches. Treat the free private-pilot exemption as one configuration, not proof that the distributed app cannot collect financial information.
- `src/pages/Messages.tsx` has both image/video and arbitrary-file attachment inputs. The arbitrary-file path could include audio; confirm allowed media types and actual upload handling before omitting audio-file categories.
- `src/components/LeaveRequestModal.tsx` sends free-text reasons and its default policy sets `reason_required: true`. `src/components/MemberAppAccessTracker.tsx` and `src/lib/notificationOpenTracking.ts` transmit activity events.
- Google's [Data safety definitions](https://support.google.com/googleplay/android-developer/answer/10787469) distinguish data collected from data shared and list "Other user-generated content" for notes and open-ended responses. Transfers to service providers acting on the developer's instructions can be exempt from the "shared" label while still being "collected." This distinction needs to be checked for each provider and data type.
- [Firebase's Android disclosure guide](https://firebase.google.com/docs/android/play-data-disclosure) states that Cloud Messaging automatically collects the app version and Firebase user agent and includes Firebase Installations, which collects a Firebase installation ID. It says the listed data is encrypted in transit. ServeSync also stores its own installation identifier and FCM token for delivery.
